심화(연수 후 선택): GitHub로 '내 주소' 만들기

Canvas 공유가 막혔거나, 오래 쓸 수업 자료를 한곳에 모으고 싶을 때 추천해요. 선생님께는 방법 1 (GitHub Pages)이 가장 간단합니다.

⚡ 방법 1. GitHub Pages — 파일 하나 + 설정 한 번 추천

  1. Canvas 코드를 복사해 index.html로 저장
  2. GitHub에서 새 저장소 만들기 (Public 선택)
  3. Add file → Upload files로 index.html 올리기 → Commit
  4. 저장소의 Settings → Pages → Branch를 main, 폴더 / (root)로 두고 Save
  5. 1~2분 뒤 https://아이디.github.io/저장소이름/ 주소 완성! → 5번 탭에서 QR 만들기
💡 이 연수 웹페이지도 이 방법으로 공개했어요 → richee-pc.github.io/26AI_design. 단원별 페이지를 더 올리려면 quiz1.html처럼 이름을 바꿔 올리고 주소 끝에 파일 이름을 붙이면 됩니다.
방법 2. GitHub + Streamlit — 파이썬 앱으로 배포하고 싶을 때

📦 폴더 구조

내-수업-웹앱/
├── app.py              ← 아래 부탁문 B로 생성
├── requirements.txt    ← streamlit 한 줄
└── htmls/
    └── index.html      ← Canvas에서 받은 코드
  1. Canvas 코드를 복사해 index.html로 저장
  2. GitHub에서 새 저장소(Repository) 만들기
  3. Add file → Upload로 htmls/index.html 올리기
  4. 부탁문 B로 app.py, requirements.txt 만들어 올리기
  5. share.streamlit.io → Create app → 저장소 선택, Main file app.py → Deploy
  6. https://○○○.streamlit.app 주소 완성!

B. app.py 부탁문

B. Streamlit 배포 부탁문# 역할 너는 Streamlit 배포 전문가다. # 목표 `htmls/index.html` 파일을 Streamlit 앱에서 열어 보여주는 배포용 `app.py`와 `requirements.txt`를 생성하라. # 필수 구현 조건 1) `app.py`는 `htmls/index.html`을 읽어 `st.components.v1.html(..., height=1000, scrolling=True)`로 넓게 보여준다. 2) 경로는 `Path(__file__).resolve().parent / "htmls" / "index.html"`을 사용한다. 3) Streamlit 기본 메뉴·여백을 숨기고 `layout="wide"`로 설정한다. 4) 파일이 없으면 한국어로 친절한 안내 메시지를 보여준다. 5) `requirements.txt`에는 `streamlit`만 포함한다. 6) 코드 생략 없이 전체 파일을 출력한다. # 출력 형식 - 먼저 ```python 코드블록(app.py 전체) - 다음 ```txt 코드블록(requirements.txt)
