📦 이 연수 웹페이지, 내 연수용으로 사본 만들기

"Gemini로 수업용 웹페이지 만들기" 연수 페이지를 그대로 복사해서 선생님의 연수·수업에 맞게 고쳐 쓰실 수 있어요. 코딩을 몰라도 Gemini Canvas나 GitHub 웹사이트에서 클릭만으로 됩니다.

👀 원본 연수 페이지 보기

가장 쉬움 방법 1. Gemini Canvas로 내 링크 만들기 (10분)

GitHub 없이 Gemini 계정만 있으면 돼요. Canvas용으로 정리한 한 파일 코드를 Gemini에 붙여 넣고, 공유 링크를 만들면 끝!

  1. 를 눌러 코드를 복사해요.
  2. Gemini를 열고 입력창 아래 도구(+) → Canvas를 켜요.
  3. 입력창에 붙여 넣기(Ctrl+V) 한 다음, 맨 아래에 이 부탁문을 이어서 붙여 넣고 보내요. 
    위 HTML 코드를 한 글자도 바꾸지 말고 그대로 Canvas에 열어 줘. 코드를 생략하거나 줄이지 말고 전체를 그대로 써 줘.
  4. 3~5분 기다리면 Canvas 오른쪽에 미리보기가 나와요. (코드가 길어서 시간이 걸려요)
  5. 내 연수 정보로 바꾸기: 아래 부탁문의 ○○을 채워서 보내요. 한 번에 모아서 부탁하는 게 빨라요. 
    맨 위 CONFIG만 이렇게 바꿔 줘. 다른 코드는 그대로 둬.
연수명: ○○○ 연수 / 날짜: 2026. ○○. ○○.(○) ○○:○○~ / 장소: ○○학교 ○○실 / 강사: ○○학교 ○○ 교사 ○○○
  6. Canvas 오른쪽 위 공유 → 링크 만들기/복사 → 이 링크를 선생님들께 보내면 돼요!
  7. (선택) 첫 화면에 입장 QR을 띄우고 싶다면: "맨 위 CONFIG의 SHARE_URL을 (복사한 공유 링크)로 바꿔 줘" → 다시 공유.
💡 Canvas판에는 구글 시트가 필요한 작품 갤러리가 빠져 있어요. 나머지 기능(아이디어 22가지·예시 화면, 부탁문 만들기·파일 첨부, 고치기 42가지, QR 만들기, 업무용·구글 설문지 탭)은 모두 들어 있어요. 예시 퀴즈는 원본 주소로 연결돼요.
⚠️ Gemini에게 "더 좋게 고쳐 줘"처럼 넓게 부탁하면 코드가 많이 바뀔 수 있어요. 꼭 "○○만 바꿔 줘. 다른 코드는 그대로 둬."처럼 범위를 정해서 부탁하세요. 학교(교육용) 계정은 공유가 막혀 있을 수 있어요.

고급 방법 2. GitHub에서 사본 만들고 내 주소로 공개하기 (10분)

  1. GitHub에 가입하거나 로그인해요. (무료)
  2. 아래 버튼을 눌러요. → Repository name에 저장소 이름(예: my-ai-training)을 적고 Public을 고른 뒤 Create repository.
    🧩 이 템플릿으로 내 저장소 만들기
  3. 만들어진 내 저장소에서 Settings → Pages로 가서, Branch를 main, 폴더를 / (root)로 두고 Save.
  4. 1~2분 뒤 https://내아이디.github.io/저장소이름/ 주소가 생겨요. 이게 선생님의 연수 페이지 주소예요!
💡 첫 화면의 입장 QR은 새 주소로 자동으로 바뀌어요. 혼자 풀기·팀 대전 퀴즈, 프롬프트 만들기, 파일 첨부, 고치기 부탁문 등 대부분의 기능은 사본에서 바로 작동해요.

✏️ (방법 2·3) 내 연수에 맞게 고칠 곳

GitHub 저장소에서 파일을 열고 오른쪽 위 연필(✏️ Edit) 버튼 → 내용 고치기 → Commit changes를 누르면 저장돼요. 파일 안에서 Ctrl+F로 ✏️ [사본 만들기]를 찾으면 고칠 곳이 바로 나와요.

파일고칠 내용필수
htmls/index.html첫 화면의 연수 날짜·장소·강사 세 줄✅
htmls/index.html1번 탭 📂 연수 자료의 슬라이드·원고 PDF 링크 (원본 연수 자료예요. 내 자료로 바꾸거나 지우기)✅
examples/jodae-quiz.htmlQUESTIONS 부분 — 우리 학교·교과 문제로 바꾸기 (문제·보기·정답 번호·해설)권장
materials/ 폴더원본 연수의 슬라이드·원고 PDF. 필요 없으면 지워도 돼요.선택
htmls/index.html 의 MY_GALLERY_API
examples/jodae-quiz.html 의 MY_API		작품 갤러리 · 실시간 대결 점수판을 쓰려면 아래 "선택" 설정 후 웹 앱 주소를 넣기선택
💡 고치기가 어렵다면 Gemini에게 부탁해도 돼요. 파일 내용을 복사해 붙여 넣고 "연수 날짜를 ○월 ○일로, 장소를 ○○로, 강사를 ○○○로 바꿔서 전체 코드를 보여 줘"라고 하면 됩니다.

선택 작품 갤러리 · 실시간 대결 점수판 연결 (5분)

갤러리와 실시간 대결은 결과를 모아 둘 곳이 필요해서, 선생님의 구글 시트를 연결해야 해요. 연결하기 전에는 갤러리가 "준비 중"으로 보이고, 실시간 대결 버튼만 꺼져 있어요.

  1. sheet.new로 새 구글 시트를 만들어요.
  2. 메뉴 확장 프로그램 → Apps Script → 기본 코드를 지우고, 내 저장소의 materials/gallery_apps_script.gs 내용을 붙여 넣고 저장.
  3. 배포 → 새 배포 → 유형: 웹 앱 → 실행: 나, 액세스: 모든 사용자 → 배포 → 권한 승인
    ("확인되지 않은 앱" 경고가 나오면 고급 → (안전하지 않음)으로 이동 → 허용. 내가 만든 스크립트라서 나오는 정상 화면이에요.)
  4. 나오는 웹 앱 URL(…/exec)을 복사해서 htmls/index.html의 MY_GALLERY_API = ''와 examples/jodae-quiz.html의 MY_API = '' 따옴표 안에 붙여 넣기.
const MY_GALLERY_API = 'https://script.google.com/macros/s/……/exec';
🔒 시트에는 갤러리 작품(제목·소개·링크·이름)과 대결 닉네임·점수가 저장돼요. 학생 개인정보는 넣지 않도록 안내해 주세요. 부적절한 작품은 시트의 숨김 칸에 x를 적으면 숨겨져요.

📁 방법 3. 파일로 받기

전체 파일을 압축(zip)으로 받아 컴퓨터에서 열어 볼 수 있어요. 다만 학생·선생님께 링크로 공유하려면 방법 1처럼 인터넷 주소로 공개해야 해요.

⬇️ 전체 파일 zip 받기 ⬇️ Canvas용 한 파일 받기

압축을 풀고 htmls/index.html을 크롬으로 열면 돼요. (인터넷 연결 필요)
