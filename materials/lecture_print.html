Ⅱ.수업용 웹페이지 아이디어 6가지

5분

다음 주 수업 하나를 떠올리고, 그 수업에 맞는 유형을 고르세요. 실습 웹페이지에서 카드를 누르면 기능이 자동으로 채워집니다.

유형교과 예시핵심 기능 (부탁문에 들어갈 내용)
🎯 퀴즈 게임수학: 일차방정식 10문항
영어: 단어 뜻 고르기		객관식 10문항, 선택 즉시 정답/오답과 쉬운 해설, 진행도 바·점수, 결과 화면과 "틀린 문제만 다시 풀기", 문제 순서 무작위
🃏 개념 카드과학: 원소 기호
사회·국어: 핵심 개념어		앞면 용어, 클릭하면 뒤집혀 설명, 이전/다음, 카드 섞기, "외웠어요" 체크와 남은 카드 수
🔬 시뮬레이션과학: 속력-거리-시간
수학: 일차함수 기울기		슬라이더로 변수 2개 조절, 그림·그래프 즉시 변화, 현재 값과 식 표시, 탐구 질문 3개와 답 칸
🗒️ 수업 활동 안내모든 교과: 모둠 활동·프로젝트 단계 안내오늘의 학습 목표, 단계별 활동 카드(펼치기), 체크리스트, 남은 시간 타이머, 성찰 질문
🎲 수업 도구담임·모든 교과: 발표자 뽑기, 모둠 편성번호 범위로 중복 없는 무작위 뽑기, 랜덤 모둠 편성, 큰 타이머 (이름 대신 번호 사용)
🪞 자기평가·출구티켓모든 교과: 이해도 체크, 배운 점 한 줄목표별 이해도 3단계, 배운 점/궁금한 점 쓰기, 요약 카드 → 화면 캡처 제출 (서버 저장 없음)
👍 처음이라면

내용이 분명한 퀴즈나 개념 카드가 가장 잘 만들어집니다. 문제와 정답을 직접 적어 주면 정확도가 크게 올라갑니다.

💪 익숙해지면

시뮬레이션은 2~3번 고칠 각오로 도전해 보세요. 학생들이 가장 오래 머무는 페이지가 됩니다.

"지금 다음 주 수업 하나를 떠올려 주세요. 단원 정리가 필요하면 퀴즈나 개념 카드, 원리를 보여 주고 싶으면 시뮬레이션, 모둠 활동이 많으면 활동 안내나 수업 도구입니다. 실습 페이지 2번 탭에서 카드의 '이걸로 만들기'를 누르시면 됩니다. 1분 드리겠습니다."

A. 수업용 웹페이지 부탁문# 역할 너는 중학교 수업용 웹페이지를 만드는 교육 전문 프론트엔드 개발자야. # 목표 아래 수업 정보로, 학생이 휴대폰·크롬북에서 바로 쓸 수 있는 '[웹페이지 유형]' 웹페이지를 Canvas에 단일 HTML 파일로 만들어 줘. # 수업 정보 - 교과·학년: [예: 과학 · 중학교 2학년] - 단원·주제: [예: 물질의 구성 - 원소와 원자] - 웹페이지 유형: [퀴즈 게임 / 개념 카드 / 시뮬레이션 / 수업 활동 안내 / 수업 도구 / 자기평가] - 학생이 할 일·핵심 기능: [예: 객관식 10문항, 즉시 정답·해설, 점수와 다시 풀기] - 디자인·분위기: [예: 밝은 파스텔 톤, 카드형, 큰 글씨와 큰 버튼] - 반드시 사용할 학습 내용: [교과서 용어·문제·정답을 붙여 넣기] # 반드시 지킬 것 1) HTML/CSS/JavaScript를 한 파일에 모두 넣고, 로그인·서버·API 키 없이 동작하게 한다. 2) 모든 글은 한국어, 중학생 눈높이의 쉬운 문장으로 쓴다. 3) 모바일 반응형으로 만들고, 글씨와 버튼을 크게 한다. 4) 상단 제목과 '오늘의 학습 목표', 활동 안내, 활동 영역, 결과·피드백 영역을 포함한다. 5) 학습 내용은 중학교 교육과정 수준에 맞추고, 확실하지 않은 사실은 넣지 않는다. 6) 학생 이름 등 개인정보를 입력받거나 저장하지 않는다. 7) 빈 입력이나 잘못된 입력에는 친절한 안내 문구를 보여준다.
💡 정확도를 높이는 한 줄: '반드시 사용할 학습 내용' 칸에 교과서의 용어·문제·정답을 직접 적어 주세요. AI가 내용을 지어내지 않고, 선생님이 준 내용으로 화면만 만들게 됩니다.

🎨 Canvas로 만들기
  1. Gemini(gemini.google.com)에 로그인
  2. 입력창 아래 도구 → Canvas 켜기
    (또는 부탁문 앞에 "Canvas에서"라고 쓰기)
  3. 복사한 부탁문 A를 붙여 넣고 보내기
  4. 오른쪽 작업대에 코드가 써지면 미리보기 클릭
  5. 직접 눌러 보고, 아래 고치기 부탁문으로 수정
✅ 미리보기 점검 3가지
  • 내용이 맞나요? 정답·용어·해설이 교과서와 같은지 (AI도 틀립니다!)
  • 눌러지나요? 모든 버튼·입력·다시 하기가 동작하는지
  • 휴대폰에서도? 화면을 좁혀도 글씨·버튼이 잘 보이는지

+심화: GitHub + Streamlit으로 '내 주소' 만들기

학생 웹앱 수업에서 학생들이 직접 따라 한 방법입니다. 공유 링크가 막혔거나, 여러 수업 자료를 한곳에 오래 모아 두고 싶을 때 추천합니다.

내-수업-웹앱/
├── app.py              ← 부탁문 B로 생성
├── requirements.txt    ← streamlit 한 줄
└── htmls/
    └── index.html      ← Canvas에서 받은 코드
순서할 일
1Canvas 코드를 복사해 index.html로 저장
2GitHub(인터넷 가방)에서 새 저장소 만들기
3Add file → Upload로 htmls/index.html 올리기
4부탁문 B로 app.py·requirements.txt 만들어 올리기
5share.streamlit.io → Create app → 저장소, Main file app.py → Deploy
6https://○○○.streamlit.app 주소 완성!
B. Streamlit 배포 부탁문 (app.py)# 역할 너는 Streamlit 배포 전문가다. # 목표 `htmls/index.html` 파일을 Streamlit 앱에서 열어 보여주는 배포용 `app.py`와 `requirements.txt`를 생성하라. # 필수 구현 조건 1) `app.py`는 `htmls/index.html`을 읽어 `st.components.v1.html(..., height=1000, scrolling=True)`로 넓게 보여준다. 2) 경로는 `Path(__file__).resolve().parent / "htmls" / "index.html"`을 사용한다. 3) Streamlit 기본 메뉴·여백을 숨기고 `layout="wide"`로 설정한다. 4) 파일이 없으면 한국어로 친절히 안내한다. 5) `requirements.txt`에는 `streamlit`만 포함한다. 6) 코드 생략 없이 전체 파일을 출력한다. # 출력 형식 - 먼저 ```python 코드블록(app.py 전체) - 다음 ```txt 코드블록(requirements.txt)
