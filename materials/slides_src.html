04Gemini Canvas로 화면 만들기

오른쪽 작업대에 코드가 써집니다. 읽지 않아도 돼요 — 미리보기만 보세요.

🎨 만드는 순서
  1. gemini.google.com 로그인
  2. 입력창 아래 도구 → Canvas 켜기
    (또는 부탁문 앞에 "Canvas에서"라고 쓰기)
  3. 3번 탭에서 받은 프롬프트 붙여 넣고 보내기
  4. 코드가 다 써지면 미리보기 클릭
  5. 학생처럼 직접 눌러 보기
✅ 미리보기 점검 3가지
  • 내용이 맞나요?
    정답·용어·해설이 교과서와 같은지 — AI도 틀립니다!
  • 눌러지나요?
    모든 버튼·입력·다시 하기가 동작하는지
  • 휴대폰에서도?
    화면을 좁혀도 글씨·버튼이 잘 보이는지
💡 Canvas 버튼이 보이지 않으면 학교 계정 설정 때문일 수 있어요. 부탁문 앞에 "Canvas에서"를 붙이거나, 옆 선생님과 함께 진행하세요.

05말로 고치기 — 한 번에 하나씩

실습 웹페이지 4번 탭의 고치기 부탁문을 누르면 복사됩니다. 붙여 넣고 보내면 끝!

글씨가 작다"글씨와 버튼을 더 크게 바꿔 줘" 문제가 부족하다"문제를 15개로 늘리고 순서를 무작위로" 해설이 어렵다"해설을 중학생 눈높이로 더 쉽고 짧게" 디자인"밝은 파스텔 톤, 카드형으로 정리해 줘" 재미"정답을 맞히면 축하 애니메이션이 나오게" 휴대폰"휴대폰 화면에서 잘리는 부분을 고쳐 줘" 오류"이 오류를 고쳐 줘: [오류 문구 그대로 붙여 넣기]"
💡 여러 개를 한 번에 부탁하면 다른 곳이 망가질 수 있어요. 하나 고치고 → 미리보기 확인을 반복하세요.
🔁 나중에 또 고치려면 Gemini 대화 기록에서 그 Canvas를 열어 이어서 부탁하면 됩니다.

06링크·QR로 학생에게 공유하기

🔗 공유 링크 → QR
  1. Canvas 오른쪽 위 공유 → 링크 복사
  2. 실습 웹페이지 5번 탭에 붙여 넣고 QR 만들기
  3. 수업 화면에 띄우거나 학습지에 인쇄
⚠️ 학교 계정은 관리자 설정에 따라 공유가 막힐 수 있어요. 그럴 땐 코드를 index.html로 저장해 GitHub Pages로 공개하세요. (저장소에 올리고 Settings → Pages → Save)

07학생에게 주기 전 체크, 그리고 기억할 세 가지

✅ 공유 전 체크리스트
  • 정답·해설을 교과서와 대조했다
  • 학생 개인정보를 입력받지 않는다
  • 교과서 본문·그림을 통째로 넣지 않았다 (저작권)
  • 휴대폰·크롬북에서 직접 열어 보았다
  • 인터넷이 안 될 때의 대안이 있다
1. 내용은 교사가

학습 내용을 직접 넣고, 정답·해설은 반드시 확인

2. 화면은 AI가
