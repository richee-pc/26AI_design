02무엇을 만들까? 수업용 웹페이지 6가지

다음 주 수업 하나를 떠올리고 유형을 고르세요. 처음이라면 퀴즈나 개념 카드부터!

🎯 퀴즈 게임

즉시 정답·해설, 점수, 틀린 문제만 다시 풀기
예) 수학 일차방정식 · 영어 단어

🃏 개념 카드

뒤집어 외우는 플래시카드, 섞기, 외웠어요 체크
예) 과학 원소 기호 · 사회 용어

🔬 시뮬레이션

슬라이더로 값을 바꾸면 그래프가 바로 변화
예) 속력-거리-시간 · 일차함수

🗒️ 수업 활동 안내

오늘의 목표, 단계별 활동 카드, 체크리스트, 타이머
예) 모둠 활동 · 프로젝트 단계

🎲 수업 도구

중복 없는 발표자 뽑기, 랜덤 모둠 편성, 큰 타이머
예) 모든 교과 · 담임 활동

🪞 자기평가·출구티켓

이해도 체크, 배운 점 한 줄 → 요약 카드 캡처 제출
예) 모든 교과 수업 정리

03AI에게 보낼 부탁문 만들기

실습 웹페이지 3번 탭에서 빈칸만 채우면 자동 완성됩니다. 파란 글씨가 내가 채울 부분!

① 역할 · 목표

누구로서, 무엇을 만들지

② 수업 정보

교과·단원·유형·기능 + 학습 내용 직접 넣기

③ 반드시 지킬 것

한 파일 · 로그인 없이 · 모바일 · 개인정보 금지

# 역할 · 목표 너는 중학교 수업용 웹페이지를 만드는 교육 전문 개발자야. 학생이 휴대폰에서 바로 쓸 수 있는 '[퀴즈 게임]' 웹페이지를 Canvas에 단일 HTML로 만들어 줘. # 수업 정보 - 교과·학년: [과학 · 중학교 2학년] - 단원: [물질의 구성 - 원소와 원자] - 핵심 기능: [객관식 10문항, 즉시 정답·해설, 점수와 다시 풀기] - 반드시 사용할 학습 내용: [교과서 용어·문제·정답 붙여 넣기] # 반드시 지킬 것 1) 한 파일에 모두, 로그인·서버 없이 동작 2) 중학생 눈높이 한국어 3) 모바일 반응형, 큰 글씨·큰 버튼 4) 확실하지 않은 사실은 넣지 않기 5) 학생 이름 등 개인정보를 입력받거나 저장하지 않기
💡 '광합성 퀴즈 만들어 줘'보다 교과서 문제 5개를 붙여 넣는 쪽이 훨씬 정확합니다. AI는 화면만, 내용은 선생님이!

04Gemini Canvas로 화면 만들기

오른쪽 작업대에 코드가 써집니다. 읽지 않아도 돼요 — 미리보기만 보세요.

🎨 만드는 순서
  1. gemini.google.com 로그인
  2. 입력창 아래 도구 → Canvas 켜기
    (또는 부탁문 앞에 "Canvas에서"라고 쓰기)
  3. 복사한 부탁문 붙여 넣고 보내기
  4. 코드가 다 써지면 미리보기 클릭
  5. 학생처럼 직접 눌러 보기
✅ 미리보기 점검 3가지
  • 내용이 맞나요?
    정답·용어·해설이 교과서와 같은지 — AI도 틀립니다!
  • 눌러지나요?
    모든 버튼·입력·다시 하기가 동작하는지
  • 휴대폰에서도?
    화면을 좁혀도 글씨·버튼이 잘 보이는지
💡 Canvas 버튼이 보이지 않으면 학교 계정 설정 때문일 수 있어요. 부탁문 앞에 "Canvas에서"를 붙이거나, 옆 선생님과 함께 진행하세요.

05말로 고치기 — 한 번에 하나씩

실습 웹페이지 4번 탭의 고치기 부탁문을 누르면 복사됩니다. 붙여 넣고 보내면 끝!

글씨가 작다"글씨와 버튼을 더 크게 바꿔 줘" 문제가 부족하다"문제를 15개로 늘리고 순서를 무작위로" 해설이 어렵다"해설을 중학생 눈높이로 더 쉽고 짧게" 디자인"밝은 파스텔 톤, 카드형으로 정리해 줘" 재미"정답을 맞히면 축하 애니메이션이 나오게" 휴대폰"휴대폰 화면에서 잘리는 부분을 고쳐 줘" 오류"이 오류를 고쳐 줘: [오류 문구 그대로 붙여 넣기]"
💡 여러 개를 한 번에 부탁하면 다른 곳이 망가질 수 있어요. 하나 고치고 → 미리보기 확인을 반복하세요.
🔁 나중에 또 고치려면 Gemini 대화 기록에서 그 Canvas를 열어 이어서 부탁하면 됩니다.

06링크·QR로 학생에게 공유하기

🔗 공유 링크 → QR
  1. Canvas 오른쪽 위 공유 → 링크 복사
  2. 실습 웹페이지 5번 탭에 붙여 넣고 QR 만들기
  3. 수업 화면에 띄우거나 학습지에 인쇄
⚠️ 학교 계정은 관리자 설정에 따라 공유가 막힐 수 있어요. 그럴 땐 코드를 index.html로 저장해 GitHub Pages로 공개하세요. (저장소에 올리고 Settings → Pages → Save)

07학생에게 주기 전 체크, 그리고 기억할 세 가지

✅ 공유 전 체크리스트
  • 정답·해설을 교과서와 대조했다
  • 학생 개인정보를 입력받지 않는다
  • 교과서 본문·그림을 통째로 넣지 않았다 (저작권)
  • 휴대폰·크롬북에서 직접 열어 보았다
  • 인터넷이 안 될 때의 대안이 있다
1. 내용은 교사가

학습 내용을 직접 넣고, 정답·해설은 반드시 확인

2. 화면은 AI가
